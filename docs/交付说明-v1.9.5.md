## 这次改了什么

按用户要求：**不要用本地模型本地规则，一定要使用 Spark 上的大模型**。

v1.9.4 的快速模式是纯本地出结论（0 网络请求）。本版恢复联网，且模型从"解释者"升级为"决策者"：

| 项目 | v1.9.4 | v1.9.5 |

| 谁选打哪张牌 | 本地 ExactSolver | **Spark 大模型** |
| 本地核算的角色 | 决定结论 | 提示词里的「程序参考」，模型可采纳可推翻 |

| 网络请求 | 0 次 | 每次分析 1 次（已和牌时 0 次） |

## 保留的护栏

- **幻觉兜底**：模型给出的牌不在已核验手牌里时，丢弃该行动、改用本地核算结果，并在"需留意"里写明。模型可以推翻本地最优，但不能编造不存在的牌。

- 需要牌河威胁、点棒、局数等完整场面分析时，仍用「结构化」模式（2 次模型请求）。
