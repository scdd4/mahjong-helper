## 启动

双击根目录 `启动.cmd` 或 `启动-v1.9.0.cmd`。正式程序为：

```text
dist-v1.9.0\MahjongStrategyAssistant\MahjongStrategyAssistant.exe
```

分发时必须保留同目录的 `_internal` 文件夹。不要只复制 EXE。

## 首次实战前的检查

1. 按 F6 打开设置，确认 **Base URL**、**模型名称**、**API 密钥** 均已填写。
   本版不再预置任何内网地址——首次使用必须显式填写，避免连到错误服务。
2. 非本机 https 之外的明文 http 地址会在诊断日志记录警告（截图与密钥明文传输）。
   实战建议优先使用 https 端点。
3. 设置保存失败时会自动回退到当前账户注册表配置（DPAPI 加密密钥），
   按时间戳读取最新配置。

## 操作要点

- 点击「截图并分析策略」：全屏画面自动定位牌桌，预览与分析使用同一份定位画面。
- 初步建议先显示，场面详解随后补全；「重新截图」会停止旧分析再处理新画面。
- F6 设置、Ctrl+S 保存、Esc 取消；F8 切换迷你模式，视图菜单可设迷你窗口置顶。
- 报告导出失败会提示更换保存位置，不会再抛出未处理异常。

**已知边界**（实战中请注意）：
- 本地不识别立直棒。若画面有人立直，模型会从原图读取，但程序无法提供
  "已确认立直"的确定性事实——涉及立直的防守建议请人工复核牌河。
- 多家立直时程序会给出"共同安全牌"交集；为空时会明确说明没有共同安全牌。
- 单侧筋（如切 8m 得 5m）只是弱线索，程序已与强筋分开，不要当绝对安全。
- 仅门清 13/14 张可本地核算；副露手牌的核算为参考，不替代模型判断。
- 高难识别（四同牌、多赤五、字牌密集、国士幺九）在合成图上落入置信灰区时
  会被安全拒绝并指出具体牌位——这是保护机制，请按提示逐张纠错或重截。
