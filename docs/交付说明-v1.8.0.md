## 使用

双击 `启动.cmd` 或 `启动-v1.8.0.cmd`。正式程序位于 `dist-v1.8.0\MahjongStrategyAssistant\MahjongStrategyAssistant.exe`，分发时保留同目录的 `_internal`。

- 点击“截图并分析策略”，全屏画面会自动尝试定位牌桌，预览与分析使用同一份定位画面。
- 初步建议先显示，场面详解随后补全；“重新截图”会停止旧分析后处理新画面。“取消”可停止详解并保留本轮初判。
- F6 打开设置，底部固定保存按钮；Ctrl+S 保存，Esc 取消。
- F8 切换迷你模式；视图菜单可设置迷你窗口是否置顶。
- 牌名显示为一万、三筒、六条、东南西北白发中，文字报告同样使用中文牌名。

## 当前数据与策略

模型会参考各家牌河、副露、立直威胁、宝牌、点棒、局数、余牌、对子和搭子形状、牌效率及假设碰后的核算。输出包括当前取舍、攻守、备选条件、后续变化、鸣牌/立直条件和点差目标。

本轮额外制作了按座位旋转和标注的点棒图，减少把上家分数当成自己的分数、把红色轮转标记当成本家风位等错误。参考资料与方法见 [策略依据与限制](策略依据与限制.md)。

程序对可靠手牌、合法张数、实际宝牌、物理数量及部分操作时机进行核验。策略取舍由开启思考的 Spark 生成，不以本地第一候选冒充模型决策。

## 保存与报错修复

用户截图中的未处理异常来自自检报告写入被拒绝。现在报告目录不可写时返回受控状态；界面导出报告失败时提示更换位置，不再以未处理异常退出。

默认设置文件仍在 `%LOCALAPPDATA%\MahjongStrategyAssistant\settings.json`。文件写入被拒绝时，会回退到当前账户 `HKCU\Software\MahjongStrategyAssistant` 中的应用配置；密钥同样使用当前 Windows 用户 DPAPI 加密。读取时比较保存时间，使用较新的配置。没有修改系统安全设置或目录权限。

若文件和当前账户配置都不能写入，打包版再尝试 EXE 旁的 `user-data/settings.json`。这是运行时生成的个人配置目录，不属于发布负载；分享程序时只分发 EXE 与 `_internal`。三处均失败时显示保存失败，原设置保留。

发布版检查还定位到一个卡死原因：Windows 上的临时文件函数可能将进程遇到的权限拒绝当成文件名冲突，反复换名重试。已替换为最多三次、仅针对实际重名重试的排他创建；权限拒绝直接进入备用加密存储，避免一直等不到保存结果。

## 验收边界

旧 v1.7.0 曾通过控件状态确认迷你切换，但不能作为 v1.8.0 验收。当前 v1.8.0 的 Windows 自动化启动调用返回 `launch_app` 超时，随后未枚举到新版窗口；先前窗口取图还曾返回 `FrameArrived timed out`。因此新版 GUI 启动、F6 保存、F8 迷你切换和实时游戏截图均未完成实机验收。打包程序的命令行计算与保存检查通过，与 GUI 验收分开记录。真实模型实测使用用户提供的图片。

单帧无法恢复完整动作历史、临时振听或对手暗牌；识别和模型仍会误判。副露核算补充的是普通型向听/进张，不等于完整点数和规则裁判。点棒拼图依赖常见布局，遇到遮挡或非默认布局仍需保留不确定性。

最终模型样本仍出现备选向听理由不一致、后续提出手里没有的安全字牌等问题；程序核验覆盖有限，不能将“没有张数警告”当成策略全对。详细说明见 `策略依据与限制.md`。
